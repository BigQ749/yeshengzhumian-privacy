隐私政策

这份说明会告诉你，夜声助眠在鸿蒙版和 Android 版中处理哪些本机数据、申请哪些权限，以及如何删除。

一、适用范围与基本原则

夜声助眠提供鸿蒙版和 Android 版，用于播放应用内环境声、管理播放组合和定时，并支持你主动选择导入本机音频。两个版本均无需注册账号、不提供在线曲库，也没有自建账号系统、广告、个性化推荐、统计分析或消息推送服务；平台权限差异见本页相应章节。

应用内声景素材随安装包提供。你的播放设置、保存的声景和导入音乐副本保存在当前设备的应用私有空间；应用不会把这些内容上传到开发者服务器。

二、应用会处理哪些信息

  • 播放和偏好设置：当前声景、环境声组合及音量、总音量、定时分钟数、页面位置，以及你为自选声景填写的名称。保存在设备本地，用于恢复你的使用状态。
  • 你选择导入的音频：你在“我的音乐”中主动选择一个 MP3、M4A、AAC、OGG 或 WAV 文件后，系统音频选择器将该文件交给应用。应用把音频副本保存在应用私有目录，并在本机保存文件名、格式、文件大小等管理信息，用于播放、显示和移除曲目。应用不会扫描设备上的其他文件。
  • 播放卡片信息：播放时，应用会向 HarmonyOS 系统媒体服务提供当前曲目或声景名称、应用封面、播放/暂停状态及定时进度，用于显示系统媒体控件。根据系统设置，这些信息可能显示在锁屏或通知控制区域；若正在播放你导入的音乐，文件名称可能作为曲目名称显示。

上述处理发生在本机，用于实现声音播放、播放状态恢复、定时关闭、锁屏控制和曲目管理。应用不读取通讯录、定位、照片、麦克风录音或通话信息，也不建立跨应用用户画像。

三、鸿蒙版权限与系统服务

  • 后台音频运行（KEEP_BACKGROUND_RUNNING）：仅在你主动开始播放时，用于支持息屏后的连续音频播放。暂停、停止或定时结束后，应用会停止相应的后台音频任务。
  • 系统音频选择器：仅在你点击添加音乐后打开。你可以自行取消或选择文件；应用不申请读取全部媒体文件的权限。
  • HarmonyOS 媒体服务：用于系统播放卡及锁屏播放、暂停、停止和定时进度控制。

应用包当前仅声明后台持续运行权限，没有声明网络、通讯录、位置、相机、麦克风或短信等权限。文件选择和系统媒体控制由 HarmonyOS 提供的界面与服务完成。

四、鸿蒙版保存期限与删除方式

播放偏好和自选声景会保留在本机，直至你清除应用数据或卸载应用。导入音乐副本会保留到你在“声音 → 我的音乐”中将其移除，或清除应用数据、卸载应用为止。

在应用内移除曲目只删除夜声助眠保存的副本，不会删除设备中的原始音频。你也可以通过 HarmonyOS 系统设置清除夜声助眠的应用数据，或卸载应用，以删除应用保存的设置、曲目记录和音频副本。

五、信息的提供、共享与公开

开发者不会通过夜声助眠收集或接收上述本机内容，不会向第三方出售、共享、转让或公开披露这些内容。应用当前没有自建服务器，也没有第三方业务 SDK。

隐私政策网页由 GitHub Pages 提供静态托管。你打开网页时，浏览器会向 GitHub 请求页面内容；GitHub 可能依其隐私声明处理网页请求所需的技术信息。夜声助眠应用不会把本机设置或音频文件发送给该网页。

六、你的权利

个人信息权利与投诉：你可在应用内查阅已保存的信息，并使用应用提供的修改、删除功能行使更正和删除权；如应用提供导出或复制功能，可用来复制信息。对于仅保存在本机的记录，开发者没有服务器副本，无法远程读取、复制或代为删除。撤回同意的入口见本政策相应说明；撤回不会自动删除已保存在本机的记录。对可由开发者处理的查阅、复制请求或隐私投诉，请联系 saijunqi@gmail.com，或通过华为应用市场的开发者联系方式提交；我们将在收到请求后15个工作日内答复。

你可以在应用中查看和调整播放设置、声景与导入曲目，并移除导入音频副本。由于应用不把这些内容上传至开发者服务器，开发者没有在线副本可供查询或删除。你也可以通过清除应用数据或卸载应用删除本机保存内容。

如需咨询本政策或反馈个人信息处理问题，可联系开发者：齐赛军，邮箱 saijunqi@gmail.com。我们会核实请求后，在适用法律要求的范围内予以答复。

七、未成年人保护

夜声助眠不面向未成年人提供专门服务，不要求用户提供年龄或身份信息。监护人如认为未成年人向应用导入或保存在设备中的内容需要删除，可以使用应用内移除功能，或通过系统设置清除应用数据。

八、政策更新

当应用功能、数据处理方式或适用要求发生变化时，我们会更新本页面并修改更新日期。若变更涉及个人信息处理方式，我们会按照适用要求在相关处理开始前通过应用内显著方式提示你。

简单来说：你选择的声音和设置留在这台设备；添加音乐时只处理你点选的文件；应用不将这些内容上传到开发者服务器。

九、Android 版补充（2.0.11 · com.yesheng.app）

本节适用于 Android 包。Android 版把同意状态和通知权限提示状态保存在 Android SharedPreferences；声景组合、音量、定时、收藏及页面状态保存在 WebView localStorage；你通过系统文件选择器主动导入的音频副本及曲名、格式、大小等管理信息保存在 WebView IndexedDB 的应用私有数据区。播放中的本机通知用于显示播放状态。

AndroidManifest 声明 WAKE_LOCK、FOREGROUND_SERVICE、FOREGROUND_SERVICE_MEDIA_PLAYBACK 和 POST_NOTIFICATIONS。唤醒锁和前台媒体播放服务仅在主动播放期间用于息屏播放；播放停止或定时结束后释放。Android 13 及以上会在你开始播放时说明用途并请求通知权限，用于显示播放通知；拒绝后仍可在前台播放，通知和后台可用性受系统设置影响。

Android 版使用系统文档选择器访问你主动点选的音频文件，不申请读取全部存储空间。应用不声明 INTERNET，也不使用相机、麦克风、定位、通讯录或传感器；播放、音频导入和本机设置不依赖网络。外部网页只会在你主动点击链接时由系统浏览器打开。

Android 版的设置和导入音频副本保留到你移除曲目、清除应用数据或卸载应用为止。应用内移除曲目只删除本应用保存的副本，不删除设备中的原音频。系统通知是否显示、前台服务和息屏播放是否可用，受 Android 版本、通知授权及设备设置影响。
